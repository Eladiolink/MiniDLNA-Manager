Atenção: Pastas de Mídia Inacessíveis (Permission Denied)

O MiniDLNA não consegue ler pastas no diretório pessoal (/home). No Arch Linux/CachyOS, o serviço vem bloqueado por padrão (ProtectHome=yes) e sem permissão de acesso.

Execute este comando no seu terminal para liberar o acesso e reindexar: 
sudo mkdir -p /etc/systemd/system/minidlna.service.d && sudo tee /etc/systemd/system/minidlna.service.d/override.conf << 'EOF'
[Service]
ProtectHome=read-only
EOF
sudo systemctl daemon-reload
sudo setfacl -m u:minidlna:x $HOME
sudo setfacl -R -m u:minidlna:rx "$HOME/Downloads"
sudo systemctl restart minidlna
